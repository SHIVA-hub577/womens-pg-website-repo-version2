SECTION 1: GLOBAL DESIGN SYSTEM & TOKENS
--------------------------------------------------------------------------------

1. COLOR PALETTE & TOKENS (CSS Variables defined in src/input.css)
   - Primary Accent: #6C63FF (Indigo Violet) — Used for primary buttons, active links, brand logos, active icons.
   - Primary Hover: #5A52E0 (Darker Indigo) — Used on primary button hover states.
   - Page Background: #F5F6FA (Off-white / Slate Tint) — Used as the body background for all app pages.
   - Surface / Card Background: #FFFFFF (Stark White) — Used for cards, sidebars, headers, form containers.
   - Text Primary (Dark): #2F2F2F (Charcoal Near-Black) — High contrast text for titles, labels, inputs, table body.
   - Text Muted: #6C757D (Medium Slate Gray) — Subtitles, metadata, table headers, placeholder text.
   - Border Color: #E2E8F0 (Light Gray Hairline) — Card borders, divider lines, table row borders, form input borders.

   - Status Badges & Alerts Palette:
     * Success / Paid / Active / Occupied:
       - Fills: rgba(34, 197, 94, 0.15) (Light Emerald Green fill)
       - Text Color: #15803D (Dark Green text)
     * Danger / Vacant / Pending / Destructive:
       - Fills: rgba(239, 68, 68, 0.15) (Light Crimson Red fill)
       - Text Color: #B91C1C (Dark Red text)
     * Warning / Partial / Raised:
       - Fills: rgba(245, 158, 11, 0.15) (Light Amber Yellow fill)
       - Text Color: #B45309 (Dark Amber text)
     * Brand Purple Badge (Room Numbers / Badges):
       - Fills: rgba(108, 99, 255, 0.15) (Light Indigo fill)
       - Text Color: #6C63FF (Primary Indigo text)

4. RESIDENT REGISTRATION PAGE (views/auth/register.ejs)

   - Buttons: Submit "Verify Email & Complete Registration" + Outlined "Resend Code" button

SECTION 4: ADMIN MANAGEMENT PAGES
--------------------------------------------------------------------------------

1. ADMIN DASHBOARD (views/admin/dashboard.ejs)
   - Route: GET /admin/dashboard
   - Purpose: High-level overview of property metrics, room capacity, and active residents.
   - Metrics Grid (.metric-grid): 4 stat cards in responsive grid (minmax 220px)
     * Metric 1: Total Rooms — Value 1.8rem bold #6C63FF
     * Metric 2: Total Residents — Value 1.8rem bold #6C63FF
     * Metric 3: Occupied Rooms — Value 1.8rem bold #22C55E (Green text)
     * Metric 4: Vacant Rooms — Value 1.8rem bold #F59E0B (Amber text)
   - Room Capacity Overview Table Card (.card):
     * Table Header (th): Room No, Sharing, Rent (₹), Advance (₹), Capacity, Occupants, Status
     * Status Badges: Occupied (Green pill badge), Vacant (Yellow pill badge), Partial (Purple badge)

2. ROOMS DIRECTORY PAGE (views/admin/rooms.ejs)
   - Route: GET /admin/rooms
   - Purpose: Complete directory of all PG rooms, capacity, and current room occupants.
   - Top Header Bar: Page Title "Rooms Overview" + Action Button "+ Add New Resident" (#6C63FF button)
   - Table Card: Responsive table container with light gray borders (#E2E8F0)
   - Data Columns: Room No (Bold text), Sharing Type (1/2/3/4 sharing), Monthly Rent (₹ formatted with en-IN commas), Advance Required (₹), Capacity (e.g. 2 beds), Current Occupants (Bullet list of names & phone numbers), Status Badge

3. TENANTS DIRECTORY PAGE (views/admin/tenants.ejs)
   - Route: GET /admin/tenants
   - Purpose: List of all active residents assigned to rooms in the hostel.
   - Top Header Bar: Title "Tenants Directory" + "+ Add New Resident" button
   - Data Columns: Tenant ID (e.g. TNT1001), Full Name, Room Badge ("Room 101" purple badge), Phone Number, Email Address, Joining Date (DD/MM/YYYY format), Monthly Rent (₹), Advance Paid (₹), Status ("Active" green badge)

4. ALLOT NEW RESIDENT / ADD TENANT PAGE (views/admin/add-tenant.ejs)
   - Route: GET /admin/tenants/new | POST /admin/tenants/new
   - Purpose: Form to register a resident and assign them to a vacant or partially occupied room.
   - Form Container: max-width 750px card
   - Section 1 (Room Allotment):
     * Background: rgba(108, 99, 255, 0.05) purple tint box with 1px border rgba(108, 99, 255, 0.2)
     * Sharing Filter Dropdown: Filter by All, 1, 2, 3, or 4 Sharing
     * Room Dropdown: Displays vacant/partial rooms with live rent & advance data attributes
     * Dynamic JS: Auto-fills Rent and Advance inputs upon room selection
   - Section 2 (Resident Details Grid):
     * Grid 2 columns (minmax 220px)
     * Inputs: Resident Name, Email, Phone, Age, Gender (Female default dropdown), Joining Date (date picker default today), Rent (₹), Advance Paid (₹)
   - Submit Button: "+ Allot Room & Save Resident" (Full width #6C63FF button)

5. RESIDENT COMPLAINTS DIRECTORY (views/admin/complaints.ejs)
   - Route: GET /admin/complaints | POST /admin/complaints/:id/resolve
   - Purpose: Inspect resident-submitted maintenance issues, photo evidence, and submit resolution notes.
   - Complaint Cards Stack:
     * Raised Card Border: 5px solid left border #F59E0B (Amber)
     * Resolved Card Border: 5px solid left border #22C55E (Green)
     * Resident Details Header: Room No, Tenant Name, Phone, Email, Raised Timestamp
     * Description Box: White-space pre-wrap problem description
     * Uploaded Evidence Thumbnail: max-width 220px, max-height 160px, rounded corners 8px, opens full image in new tab on click
   - Resolution Form Box (for Raised issues):
     * Tinted Form Container: rgba(108, 99, 255, 0.05) fill
     * Textarea: Resolution Description / Action Taken (required)
     * File Input: Upload Resolution Photo Evidence (Max 5MB)
     * Resolve Button: Green solid button (#22C55E fill, #FFFFFF text, padding 0.65rem 1.5rem)

6. RENT PAYMENTS OVERVIEW (views/admin/payments.ejs)
   - Route: GET /admin/payments | POST /admin/payments/:tenantId/update | GET /admin/payments/export
   - Purpose: Track monthly rent collection status, record manual payment status updates, and download CSV reports.
   - Header Controls:
     * Month Selector Dropdown: Select current month or past 11 months (auto-submits form on change)
     * CSV Download Button: Outlined button with Download SVG icon
   - Summary Cards (3 Metric Cards):
     * Total Expected Rent: ₹ Total
     * Total Collected: ₹ Total (Green text #22C55E)
     * Pending Amount: ₹ Total (Red text #EF4444)
   - Payments Table:
     * Data Columns: Resident Details (Name + Tenant ID), Room, Monthly Rent, Amount Paid (Color-coded text), Status Badge (Paid = Green badge, Partial = Yellow badge, Pending = Red badge), Last Payment Date & Updated By Admin Email, Quick Action Inline Status Form
     * Action Dropdown: Select Paid / Partial / Pending status + Save button. Selecting 'Partial' triggers a JS prompt asking for partial payment amount (₹1 to ₹Rent-1)

7. REMOVE RESIDENT SELECTION PAGE (views/admin/remove-tenant.ejs)
   - Route: GET /admin/remove-tenant | POST /admin/tenants/:tenantId/request-removal
   - Purpose: Cascading dropdown interface to select an active resident and send a 6-digit removal OTP to their email.
   - Container: max-width 750px card
   - Destructive Warning Box:
     * Background: rgba(239, 68, 68, 0.05) light red fill, Border: 1px solid rgba(239, 68, 68, 0.2), Header: Red text #B91C1C with Warning Shield SVG
     * Warning Text: "Initiating removal emails a 6-digit verification OTP to the resident. You must enter the OTP on the next screen to finalize removal."
   - Cascading Form Controls:
     * Step 1 Dropdown: Select Sharing Type (1, 2, 3, 4 sharing)
     * Step 2 Dropdown (Cascading): Select Room Number (enabled after step 1)
     * Step 3 Dropdown (Cascading): Select Resident to Remove (enabled after step 2)
   - Submit Button: Red solid button (#EF4444 fill, text "Send Removal OTP to Resident", disabled & 0.6 opacity until resident selected)

8. VERIFY REMOVAL OTP PAGE (views/admin/verify-removal-otp.ejs)
   - Route: POST /admin/remove-tenant/verify
   - Purpose: Admin enters the 6-digit OTP received by the resident to confirm tenant removal.
   - Container: max-width 600px card centered
   - Details Card Box:
     * Background: rgba(108, 99, 255, 0.08) purple fill
     * Resident Name, Email Address, Room Number
   - Form Controls:
     * OTP Code Input: 6-digit pattern, text-align center, letter-spacing 4px, font-size 1.2rem
   - Action Buttons:
     * Submit: Solid Red Button (#EF4444 fill, text "Verify OTP & Complete Removal")
     * Cancel Button: Outlined button returning to removal selection
